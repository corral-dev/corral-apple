# Conversation time

Owner requirement (2026-10-07): native-client conversations show approximate message times between messages, like WeChat. This is shared by Mac and iPhone.

- Use a centred, secondary-colour system Text label without a background, border or control. The first dated visible row, at least five minutes since the previous displayed time, and a local-calendar day change start a new time group. Consecutive activity remains one collapsed card.
- Today shows hours and minutes; yesterday shows the localized day name and time; earlier dates show month/day and time, adding the year outside the current year. Use the viewer's local calendar, time zone and locale.
- Missing, nonfinite, nonpositive or out-of-range timestamps produce no label and never acquire an invented time. Activity cards use their first source message's timestamp; unknown times do not advance the last displayed time.
- Keep existing message/tool row identities and scrolling anchors. Labels belong to the corresponding row so history paging, message jumps and streaming use the existing scroll path.

Native API: SwiftUI `Text`, `TimelineView(.periodic)` for day-relative label refresh, and Foundation `Date.FormatStyle` / `DateFormatter` for locale-aware formatting; available in the installed Xcode 27 SDK. Official references: [Text](https://developer.apple.com/documentation/swiftui/text), [Date.FormatStyle](https://developer.apple.com/documentation/foundation/date/formatstyle), [TimelineView](https://developer.apple.com/documentation/swiftui/timelineview). Reuse the existing Corral message list; WeChat is a visual behavior reference, not a reusable source implementation.

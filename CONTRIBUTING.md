# Contributing

Report bugs with your OS, app version and reproduction steps. Replace private session content, host addresses and account information with synthetic examples. Use private security reporting for sensitive findings.

Keep iPhone and Mac logic in their owning shell or shared module. Run portable tests and localization checks; compile affected app targets and verify real behavior on supported devices. Changes to shared UI require acceptance on both clients. Do not introduce maintainer infrastructure, personal signing information or bundled relay defaults.

Before a contribution is merged, explicitly accept [CLA.md](CLA.md) in the pull request using your GitHub account. Do not submit personal contact details, credentials or signatures in repository files. Maintainers record the agreement with the contribution; an unaccepted agreement means the contribution cannot be merged.

Include third-party origins and licenses for any material you add. Software is GPL-3.0-only; Corral branding follows [BRAND_POLICY.md](BRAND_POLICY.md).
